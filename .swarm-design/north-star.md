# Design North Star

This codebase is becoming a pattern-based multi-agent orchestration framework built on opencode. It serves developers who want to compose AI agents into reliable, deterministic workflows using well-known coordination primitives — blackboard, council, orchestrator-worker, debate-judge, critic-loop, and map-reduce — as first-class, typed abstractions with formal lifecycle semantics. Each pattern implements a common interface (init, step, shouldTerminate, onResult) and registers through a central PatternRegistry, making dispatch declarative rather than ad-hoc. Unlike AutoGen or CrewAI, which offer flexible but underspecified agent topologies, this framework treats patterns as the unit of composition and guarantees termination, convergence, and reproducibility. The real product value isn't just naming patterns — it's making pattern execution inspectable and composable: developers should be able to nest a critic-loop inside an orchestrator-worker, observe each state transition, and get deterministic replays of any multi-agent run. The typed Pattern interface is the keystone: without it, composability and observability are just promises, not guarantees.
